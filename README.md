# Data Science 2017

Exercises and projects from my 2017 Springboard Data Science Career Track and Dataquest coursework, combined from separate repositories. Each folder was its own repository, and its full commit history is kept here.

| Folder | Topic | Language |
|---|---|---|
| `regression/linear-regression` | Linear regression on housing data | Python |
| `regression/logistic-regression` | Classifying gender from height and weight, with regularization and grid search | Python |
| `regression/flight-delays-r` | Logistic regression on flight delays | R |
| `classification/naive-bayes` | Naive Bayes text analysis of Rotten Tomatoes reviews | Python |
| `classification/knn-credit-r` | Nearest neighbors on German credit default data | R |
| `clustering/customer-segmentation` | K-means customer segmentation on wine offers | Python |
| `clustering/unemployment-r` | K-means clustering of US state unemployment | R |
| `recommendation-system` | Recommender on MovieLens | Python |
| `time-series` | Time series tools, from dates and time zones to forecasting | Python |
| `inferential-statistics` | Hypothesis testing: body temperature, hospital readmissions, hiring discrimination | Python |
| `data-wrangling/json` | JSON wrangling of World Bank projects | Python |
| `data-wrangling/xml` | XML wrangling of the Mondial database | Python |
| `sql` | Yammer user engagement analysis | SQL |
| `dataquest` | Dataquest guided projects | Python |
| `capstone-proposal` | Capstone project ideas and proposal | docx |
| `nlp/european-language-classification` | Detecting European languages on the Europarl corpus with n-gram logistic regression (Startup.ml challenge) | Python |

The original repositories are archived on GitHub and remain read-only.
